# Ignore Files from the Eyes of Prettier

In some scenarios, it can be useful to [ignore files](https://prettier.io/docs/ignore/) from the watchful eyes of `prettier`.

For example, [a husky pre-commit hook](../../husky/guides/create-a-pre-commit-hook.md) might [generate some documentation](../../terraform-docs/guides/automate-generation-of-terraform-module-documentation.md), and then [check that files are formatted properly](../../prettier/guides/check-files-are-formatted.md). This is all well and good when the documentation generator produces documentation that is to `prettier`'s liking, but when the generator produces documentation with a bit of pizzaz (an extra space here or there, for example), your pre-commit scipt can find itself in deadlock state, the generator always producing goods that `prettier` deems [totally unacceptable](https://youtu.be/Q-WHRJPlL5g).

To ignore specific files from `prettier`, create a `.prettierignore` file, and add whatever you need there.

Here's an example that ignores `README.md` files [generated by `terraform-docs`](../../terraform-docs/guides/automate-generation-of-terraform-module-documentation.md) in the context of a [standard module structure](../../terraform/terraform.md#standard-module-structure).

`.prettierignore`

```
modules/**/README.md
```
