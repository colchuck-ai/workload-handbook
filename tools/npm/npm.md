# NPM

We use the node package manager (NPM) to install and run useful packages like [commitlint](../../tools/commitlint/commitlint.md), [husky](../../tools/husky/husky.md), and [semantic-release](../semantic-release/semantic-release.md).

It's important to [ignore npm files from git](./guides/ignore-npm-files-from-git.md).
