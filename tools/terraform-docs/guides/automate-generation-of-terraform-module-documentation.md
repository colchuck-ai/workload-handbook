# Automate Generation of Terraform Module Documentation

1. Ensure that your repository structure matches the [standard deployment structure](../../terraform/terraform.md#standard-deployment-structure) or the [standard module structure](../../terraform/terraform.md#standard-module-structure).
2. If not already created, [create a pre-commit hook](../../../tools/husky/guides/create-a-pre-commit-hook.md)
3. [Install terraform-docs](./../terraform-docs.md#installation)
4. Add the following configuration `.terraform-docs.yml` file to your project root:

   ```yml
   formatter: "markdown table"
   settings:
     anchor: false
     html: false
   ```

5. Add the following script to `./scripts/pre-commit-generate-module-documentation.sh`

   ```sh
    #!/usr/bin/env sh

    find . -type d -regex "^\\.[^\.]*/modules$" | while read -r modules_dir; do
        for module_dir in $modules_dir/*; do
            echo "Generating documentation for module directory: $module_dir"
            if terraform-docs "$module_dir" > "$module_dir/README.md"; then
                prettier --write "$module_dir/README.md"
                git add -v "./$module_dir/README.md"
            fi
        done
    done
   ```

6. Make the script executable:

   ```sh
   sudo chmod +x ./scripts/pre-commit-generate-module-documentation.sh
   ```

7. Add a `generate-module-documentation` script to your `package.json` scripts:

   ```json
   {
     "scripts": {
       "generate-module-documentation": "./scripts/pre-commit-generate-module-documentation.sh"
     }
   }
   ```

8. Add the following line to your `./.husky/pre-commit` script:

   ```sh
   npm run generate-module-documentation
   ```

9. Instruct `prettier` to [ignore](../../prettier/guides/ignore-files.md) `README.md` files generated by `terraform-docs` by including a `.prettierignore` file with the following content.

   ```
   modules/**/README.md
   environments/**/README.md
   ```
