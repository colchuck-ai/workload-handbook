## Protected Branches

Configure protected branches using [these instructions](https://docs.gitlab.com/user/project/repository/branches/protected/) with the following settings:

- Branch: (the branch name or wildcard)
- Allowed to merge: `Developers and Maintainers`
- Allowed to push and merge: `No one`
- Allowed to force push: `No`
- Require approval from code owners: `Yes`
